# 🎉 Birthday Surprise - Glassmorphism Edition

一個華麗的雙主題生日祝福互動網頁，採用現代 Glassmorphism（玻璃擬態）設計風格。

## ✨ 特色功能

### 🎨 視覺設計
- **玻璃擬態質感**：磨砂玻璃效果 + 半透明層次
- **Aurora 動態背景**：三色流體光球緩慢移動
- **主題色漸層**：精緻的漸層文字與按鈕

### 🎮 互動遊戲
- **數學主題**：解開算式獲得幸福通解
- **貓咪主題**：尋找隱藏的貓咪
- **解鎖機制**：必須完成遊戲才能看到祝福

### 🎆 動畫效果
- Canvas 煙火特效
- 平滑的主題切換動畫
- 震動反饋（支援行動裝置）
- 微互動設計（Hover/Active 效果）

## 🚀 使用方式

1. 直接打開 `index.html` 即可使用
2. 或訪問 GitHub Pages：[Live Demo](#)

## 📝 客製化

修改 JavaScript 中的 `config` 物件即可客製化內容：

```javascript
const config = {
    math: {
        name: 'Alice',        // 壽星名字
        message: '...',       // 祝福文字
        gameHint: '...',      // 遊戲提示
        decorTag: '...',      // 裝飾標籤
    },
    cat: {
        name: 'Sophie',       // 壽星名字
        message: '...',       // 祝福文字
        gameHint: '...',      // 遊戲提示
        decorTag: '...',      // 裝飾標籤
    }
};
```
